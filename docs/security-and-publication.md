# Security and publication boundary

The package was screened before publication for private keys, tokens, API keys, passwords, cookies, environment files, commercial Innovus/PDK files, benchmark archives, large tensors, checkpoints, binaries, and core dumps.

The repository is intended to be private. Before making it public, re-run a secret scanner and review all absolute paths in manifests. Do not add raw benchmark data, paper PDFs, vendor trees, or credentials.
